# LoveZrap

LoveZrap is a personalized gifting experience built with React. Visitors can explore gift creations and submit a custom gift request; the app also includes an administration area for managing requests and site content.

## Requirements

- Node.js
- npm

## Getting started

```bash
npm install
npm run dev
```

Vite prints the local development URL after the server starts.

## Available commands

```bash
npm run dev      # Start the development server
npm run build    # Create a production build
npm run preview  # Preview the production build locally
npm run format   # Format the project with oxfmt
```

## Project layout

- `src/app/` - Application routes and route composition
- `src/components/` - Shared layout and UI components
- `src/features/` - Feature-specific workflows, including gift requests
- `src/pages/` - Public and admin pages
- `src/data/` - Brand and page content
- `public/` - Static assets served directly by Vite

## Stack

React 19, TypeScript, Vite, Tailwind CSS 4, React Router, and Lucide React.
